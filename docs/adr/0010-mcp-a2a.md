# ADR-010: MCP server and A2A agent card over one tool layer

- Status: accepted
- Date: 2026-11-26

## Context

Other agents (Claude Desktop, IDE agents, other A2A agents) should be able to use OpsPilot's
search and triage. They are themselves driven by untrusted prompts, so whatever we expose must be
safe even if the calling agent is hijacked.

## Decision

- **One tool layer** (`agent/tools.py`) behind both protocols, so behaviour and safety checks are
  identical. It **never imports `agent.actions`** (a unit test parses the imports of every
  protocol module). The only side effect available is `triage_issue`, which starts the durable
  workflow; posting still needs a human approval in the UI.
- **Bounded inputs**: repos allow-listed to `REPOS`, query ≤ 2,000 chars, body ≤ 20,000, `k` ≤ 20.
- **Untrusted outputs**: thread/search text is secret/PII-redacted and returned with a note that
  it is untrusted, because the calling model will read it.
- **MCP** with the official Python SDK v2 (`MCPServer`):
  - tools carry annotations: `read_only_hint` for the three read tools;
    `destructive_hint=false`, `open_world_hint=false` for `triage_issue`;
  - served as stateless streamable HTTP mounted in the API at `/mcp/`, with DNS-rebinding
    protection and localhost-only hosts/origins, and over stdio for Claude Desktop;
  - input errors are raised as `ToolError` so the client sees them; any other exception is
    hidden by the SDK.
- **A2A v1.0** (released 2026-03), not 0.3:
  - card at `/.well-known/agent-card.json` with `supportedInterfaces`;
  - PascalCase JSON-RPC methods (`SendMessage`, `GetTask`) and parts keyed by member (`text`,
    `data`);
  - `A2A-Version: 1.0` is required. An empty header means 0.3 per the spec, which gets
    `VersionNotSupportedError` (-32009).
  - Triage runs map to tasks; awaiting human approval is `TASK_STATE_INPUT_REQUIRED`.
  - Streaming and push notifications are declared unsupported in the card.

## Consequences

- No authentication: both protocols are for localhost. Adding OAuth (MCP auth / A2A
  `securitySchemes`) is the next step before exposing them anywhere else.
- `get_thread` is MCP-only; A2A callers get the thread data through `triage_issue` artifacts.
